# Farms Listing & Reviews — Design Spec

**Date:** 2026-06-08
**Status:** Approved

## Overview

Add a public farm discovery flow: a browsable list of farms at `/farms`, a "Ферми" nav link, and a reviews section (star rating + text) on each farm's detail page.

## Goals

- Buyers can discover farms without knowing their URL
- Each farm page shows products + community reviews
- Any authenticated user can leave a review (multiple per user allowed)
- Farm detail page remains public (no auth required to view)

## Data Model

### New table: `farm_reviews`

```sql
CREATE TABLE farm_reviews (
  id          SERIAL PRIMARY KEY,
  farm_id     INTEGER NOT NULL REFERENCES farms(id) ON DELETE CASCADE,
  user_id     INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  rating      SMALLINT NOT NULL CHECK (rating BETWEEN 1 AND 5),
  text        TEXT NOT NULL CHECK (char_length(text) >= 1),
  created_at  TIMESTAMP NOT NULL
);
```

Average rating is computed on read via `AVG(rating)` — not stored as a column.

## Backend

### New endpoints

| Method | URL | Auth | Description |
|--------|-----|------|-------------|
| `GET` | `/api/v1/farms` | — | Paginated farm list |
| `GET` | `/api/v1/farms/:id/reviews` | — | Paginated reviews for a farm |
| `POST` | `/api/v1/farms/:id/reviews` | ✓ | Create a review |

### Modified endpoint

`GET /api/v1/farms/:id` — adds `avgRating: number | null` and `reviewCount: number` to the existing response.

### `GET /api/v1/farms` response

```json
{
  "data": [
    {
      "id": 1,
      "name": "Ферма Петренка",
      "location": "Полтавська обл.",
      "coverImagePath": "https://...",
      "activities": ["Рибалка", "Збір урожаю"],
      "reviewCount": 3,
      "avgRating": 4.7
    }
  ],
  "meta": { "currentPage": 1, "lastPage": 5, "total": 42 }
}
```

Ordered by `created_at DESC`. Page size: 20.

### `GET /api/v1/farms/:id/reviews` response

```json
{
  "data": [
    {
      "id": 1,
      "rating": 5,
      "text": "Дуже свіжі овочі!",
      "createdAt": "2026-06-03T10:00:00.000Z",
      "user": { "id": 42, "fullName": "Олена В." }
    }
  ],
  "meta": { "currentPage": 1, "lastPage": 2, "total": 3 }
}
```

Ordered by `created_at DESC`. Page size: 20.

### `POST /api/v1/farms/:id/reviews` body

```json
{ "rating": 5, "text": "Чудова ферма!" }
```

Returns the created review (201). Returns 404 if farm not found, 422 if validation fails.

## Frontend

### New route: `/farms` (farm list)

Displays a responsive grid of farm cards. Public, no auth required.

**Farm card (style A):**
- Cover image (gradient fallback if none)
- Farm name + location
- Activity tags (pills)
- No rating on the card

### Modified route: `/farms/$id` (farm detail)

Adds a reviews section below the products list:
- Header: "Відгуки (N)" + average stars + score (e.g. ★ 4.7)
- If authenticated: form with 5-star picker + textarea + submit button
- If not authenticated: "Увійдіть, щоб залишити відгук" text link
- List of reviews: author name, stars, text, date
- Pagination (load more button)

### Navigation

"Ферми" link added to `app-layout.tsx` for all users (no auth condition), between the logo and existing links.

## Error Handling

- `POST /api/v1/farms/:id/reviews` without auth → 401
- Invalid rating (not 1–5) or empty text → 422 with field errors
- Farm not found → 404
- Frontend review form: shows inline error message on failure, disables submit while pending

## Out of Scope

- Editing or deleting reviews
- Moderation / report flow
- Filtering farms by activity or rating
- Farm owner replies to reviews
